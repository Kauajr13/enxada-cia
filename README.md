# Enxada & Cia 🌱 | Cultivating a Better Future

![Game Banner](caminho/para/seu/banner-ou-screenshot-principal.png)
> *A sustainability-focused farming game developed with Unity and C#.*

---

## 📖 About the Project

**Enxada & Cia** isn't just a farming simulator; it's a project born from the intersection of game development passion and social responsibility.

Developed during my Computer Science degree at UNESP for the Computer Graphics discipline, the game aims to raise awareness about the **UN Sustainable Development Goal 2 (Zero Hunger)**. The goal was to create an engaging experience where players learn the importance of sustainable agriculture and resource management through intuitive gameplay.

As the lead developer on this project, I was responsible for the full development lifecycle, transforming a concept into a playable experience using the Unity engine.

---

## 🎮 Key Features

* **Immersive Farming Mechanics:** An intuitive system to till soil, plant seeds, water crops, and harvest produce.
* **Resource Management:** Players must balance their inventory space, manage tool durability, and optimize harvest cycles.
* **Engaging UI/UX:** A clean, custom-designed user interface built to provide clear feedback to the player without cluttering the screen.
* **Low-Poly Aesthetic:** A charming visual style optimized for performance.

---

## 🛠️ Technical Highlights (Under the Hood)

This project was a deep dive into C# scripting and the Unity ecosystem. Key technical achievements include:

* **Custom C# Architecture:** The game logic was built entirely from scratch. I avoided relying on pre-made "game kits" from the Asset Store to ensure full control over the code structure and gain a deeper understanding of game loops.
* **Unity Physics Integration:** Implemented rigidbodies and colliders for realistic interactions between the player, tools, and the environment (e.g., tilling the ground, item pickups).
* **Robust State Management:** Developed a system to handle different game states seamlessly (Main Menu, Gameplay Loop, Inventory System, Pause Screen).
* **UI Event System:** Utilized Unity's UI toolkit connected to C# events to update scores, inventory slots, and player stats in real-time.


## 💻 How to Run the Project

You need **Unity 6.0** to run this project.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Kauajr13/Nome-do-Repo-Enxada.git](https://github.com/Kauajr13/Nome-do-Repo-Enxada.git)
    ```
2.  Open **Unity Hub**.
3.  Click **"Add"** and select the cloned project folder.
4.  Open the project (it might take a while to import assets first).
5.  Open the main scene located in `Assets/Scenes/MainScene.unity` (adjust path if necessary).
6.  Press the **Play** button in the editor.
